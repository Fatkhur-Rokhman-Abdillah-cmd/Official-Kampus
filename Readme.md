# Website Official Politeknik Negeri Cilacap

Website informasi kampus dengan 4 halaman (Beranda, Profil, Kegiatan, Kontak)
menggunakan HTML, CSS, dan JavaScript murni tanpa framework.

## Struktur
- `index.html` — Beranda
- `profil.html` — Profil
- `kegiatan.html` — Kegiatan
- `kontak.html` — Kontak
- `css/style.css` — satu file CSS
- `js/script.js` — satu file JavaScript
- `images/` — aset gambar

## Fitur
- Navbar responsif dengan menu mobile
- Mode gelap (dark mode) dengan penyimpanan localStorage
- Filter kategori kegiatan
- Validasi formulir kontak
- Animasi scroll reveal & counter
- Back to top
- Responsive di semua ukuran layar
